# Sample Builds — Sony A7 IV

These are pre-built JPEG cards committed to the repo so you can hardware-test
without setting up a Python environment. They are regenerated by hand
periodically; for a fresh build, run `posingincam build --camera sony-a7iv`.

## Files

- `DSC00099.JPG` — Pose P-001 "Walking Hand in Hand". Filename starts with
  `DSC` and is high-numbered (99) so it slots in cleanly behind your real
  photos in a Sony A7 IV's `100MSDCF` folder.

## How to use this for a hardware test

1. **Download the JPG**: open it on GitHub and click the "Download raw file"
   button (top right of the file view), or use this URL:
   `https://github.com/inprincipiophotography-ctrl/PosingInCam/raw/claude/photography-pose-app-jGwu9/samples/sony-a7iv/DSC00099.JPG`

2. **Format an SD card in the camera**:
   - Insert the card.
   - Menu → Setup → Media → Format → confirm.

3. **Take one test photo**. Sony will write `DCIM/100MSDCF/DSC00001.JPG`.

4. **Eject the card** and plug it into your Mac via card reader.

5. **Drop our JPG into the same folder**:
   ```bash
   cp ~/Downloads/DSC00099.JPG /Volumes/<your-sd-card>/DCIM/100MSDCF/
   ```

6. **Eject cleanly** (Finder → eject button). Don't pull the card out
   without ejecting.

7. **Insert into camera, hit Play (▶)**. Scroll right past your test photo.
   You should see our pose card.

## What "working" looks like

- Single-image view: card renders sharp, full-screen, full resolution.
- Zoom (top dial): you can zoom into the text and read it.
- Grid view (button next to Play, ⊞ icon): shows just the line-art illustration —
  no text. That's the embedded thumbnail working.

## What to send back if it doesn't work

- A photo of the camera screen (whatever it shows: error message, blank,
  generic icon, anything).
- The exiftool dump of the file (if you have exiftool):
  ```bash
  exiftool -G1 -a -s DSC00099.JPG | head -80
  ```
