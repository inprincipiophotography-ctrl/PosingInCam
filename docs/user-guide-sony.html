02 · Setup p. 3

Prep the SD card

The whole setup takes three minutes. Do it once; the pack stays put and survives any future body upgrade in the Sony Alpha line.

01
Format the SD card in your camera
Insert the SD card in your camera. Go to MENU → Setup → Media → Format and confirm.
This wipes the SD card and creates the structure Sony expects. We recommend using a dedicated SD card just for pose references; that way it doesn't mix with your shoot cards.
Tip: an old 16 GB or 32 GB SD card is more than enough. The whole pack takes ~25 MB.
02
Take one photo
Shoot anything; a wall, a table, whatever. The camera will automatically create the DCIM/100MSDCF/ folder on the SD card. That's the standard Sony structure we need.
Your first photo lands on the SD card as DSC00001.JPG; you'll delete it in the next step before copying the pack.
03
Insert the SD card into your computer
Pull the SD card out of the camera and plug it into a Mac or PC via a USB reader or built-in slot.
The SD card mounts as a volume on your Desktop (on Mac usually as "Untitled"; on Windows as a drive letter).
02 · Setup (continued) p. 4

Copy the poses and go

04
Delete the test photo, then copy the poses
On the SD card, open DCIM/100MSDCF/ and delete the DSC00001.JPG you took in step 02.
From the ZIP you received, open DCIM/100MSDCF/ and select every DSC0xxxx.JPG file. Drag and drop them all into the DCIM/100MSDCF/ folder on the SD card.
Important: the pose files have to go into the 100MSDCF folder, not into a custom folder. Sony cameras only show files from standard MSDCF folders in playback.
05
Eject the SD card
Mac: click the ⏏ icon next to the SD card in Finder, or press cmd+E. Windows: use "Safely Remove Hardware".
Don't yank the card before ejecting; Sony is sensitive to incomplete FAT writes and the SD card can refuse to mount the next time.
06
Recover Image Database
Put the SD card back into the camera. Go to MENU → Setup → Media → Recover Image Database; confirm Yes.
The camera spends 10-30 seconds indexing every file on the SD card. When it finishes, press Playback (▶). Every pose is right there.
Run this step every time you add or change files through your computer. Sony cameras keep an internal index that doesn't refresh on its own; it only updates when you trigger Recover.
03 · On shoot day p. 5

On shoot day

Workflow during a shoot: as simple as scrolling through your own photos. Joystick to navigate; zoom button for detail; info button for the prompt text.

Recommended setting before you shoot Set MENU → Playback → View Mode → Folder View (Still). In Folder View, every pose is grouped in one place; scroll through them with the joystick like a standard photographic reference. In Date View the pack is separated from your shoot photos (poses are date-stamped to January 2024), which is useful if you don't want them mixed in chronologically.

Workflow during the shoot

→
Before each new pose
Press Playback; joystick to the pose you want. Show it to your subject on the camera screen.
⊕
Details in the prompt
Press DISP to reveal the text overlay; the pose description, framing notes, and light direction.
○
Back to shoot mode
Half-press the shutter; the camera exits playback immediately and you're ready to shoot. No seconds lost.
What you do NOT do: pull out a phone. Unlock a screen. Search for signal. In Principio Photography
04 · Help p. 6

If something doesn't work

Most issues fall into one of three buckets. Fix it yourself in 30 seconds, or write in if that doesn't do it.

"I inserted the SD card and the poses aren't showing in playback."
You haven't run Recover Image Database (step 06). Sony cameras keep an internal index that ignores manually-added files until you trigger a rebuild. Go to MENU → Setup → Media → Recover Image Database; confirm Yes; wait 10-30 s.
"A pose displays, but in the wrong orientation."
This shouldn't be possible with a valid output from us; please let us know. Send a photo of the camera screen (snap it with your phone) plus your camera model and firmware version (MENU → Setup → Setup Option → Version) and we'll sort it.
"I have an A7R V / A1 II / a newer Sony Alpha; does it work?"
Most likely yes; every modern Sony Alpha body shares the JPEG validation logic our pipeline targets. We haven't physically tested every model, so if you run into trouble, the fastest first check is to run Recover Image Database. If that doesn't help, write in and we'll work it out together.
"Some poses are missing from playback, but the file is on the SD card."
The camera's image index didn't pick up every file on the last rebuild. Take the SD card out, put it back in, and run MENU → Setup → Media → Recover Image Database again. If the same poses keep failing, write in and include the file numbers so we can check.
Email us with a description of the problem and, if you can, a photo of the camera screen.
